# El soplo de Ehécatl

App del rally de la posada 2026 del Campus Concá (UAQ). Se abre en el celular y, después de abrirla una vez, funciona sin datos.

Dirección para jugar: https://soplo-ehecatl.campusconcauaq.workers.dev/

Este repositorio guarda solo la versión publicada de la app. El contenido del juego se prepara aparte y aquí llega ya cifrado.
